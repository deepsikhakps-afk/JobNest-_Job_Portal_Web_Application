# 💼 JobNest – Job Portal Web Application

JobNest is a responsive **job portal web application** built using **React.js and Bootstrap 5**. It provides a simple platform for users to browse job opportunities, search and filter jobs, apply for jobs, and track their applications through a personal dashboard.

## 🚀 Features

* 🔐 Login and Registration interface
* 💼 Browse available job listings
* 🔎 Search jobs by title, company, or skill
* 🎯 Filter jobs by:

  * Category
  * Location
  * Job Type
* 📝 One-click job application
* 📊 User dashboard
* 👤 Profile section
* 📋 Application tracking
* 📌 Application status:

  * Pending
  * Review
  * Selected
  * Rejected
* 📱 Responsive design
* 🎨 Modern UI using Bootstrap 5
* ⚡ React components and state management

The application includes predefined job listings and application data for demonstration purposes.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* React.js 18
* Bootstrap 5
* Bootstrap Icons
* Babel

React, ReactDOM, Babel, and Bootstrap are loaded through CDN links, so no build setup is required for this version.

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/JobNest.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the application

Since the project uses CDN-based React and Bootstrap, you can open `index.html` directly in a browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.

## 🔎 Job Search & Filtering

Users can search jobs by:

* Job title
* Company
* Skills

They can also filter jobs based on category, location, and employment type.

## 📊 Dashboard

The dashboard provides:

* Overview
* Profile
* Job Listings
* Applications
* Application statistics

Users can see the number of applications sent, applications under review, and selected applications.

## 📝 Application Tracking

When a user applies for a job, the application is added to the application list and displayed with its current status.

## 🎯 Purpose

The main purpose of JobNest is to demonstrate the development of a modern frontend job portal with React components, state management, form validation, filtering, and dashboard functionality.
